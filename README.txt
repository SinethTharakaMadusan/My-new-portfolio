SETUP
1. Put your image/ folder (main banner.png, about.jpeg, project1.png) next to index.php.
2. Create a MySQL database and import database/schema.sql
3. Copy config.example.php to config.php and fill in DB details.
4. php setup_admin.php yourname "a-long-password"   then delete setup_admin.php
5. Public site: /index.php     Admin: /admin/login.php
index.original.html is your untouched original page (backup).
